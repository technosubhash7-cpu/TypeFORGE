# TypeForge

A free, browser-based typing tutor starter project. TypeForge is an independent learning project inspired by the general idea of typing tutors; it is not affiliated with or a copy of TypingMaster.

## Features in this starter
- Modern responsive dashboard
- 12 structured beginner lessons
- Timed 1, 3 and 5 minute typing tests
- Live WPM, accuracy and character counts
- Local progress and recent test history using `localStorage`
- Dark interface with a light-theme toggle
- Works without a backend or account

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.

For best results, use a local static server or the VS Code Live Server extension.

## Publish free with GitHub Pages
1. Create a new GitHub repository named `typeforge`.
2. Upload `index.html`, `style.css`, `app.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide your public website URL after deployment.

## Notes
- Progress is stored in the current browser on the current device. It does not sync between devices.
- The starter version includes English practice. Hindi typing and advanced analytics can be added in later releases.
- This project uses plain HTML, CSS and JavaScript, so no paid hosting or build tools are required.
